# AI SQL Assistant

An AI-powered SQL Assistant built using Flask, Gemini API, MySQL, HTML, CSS, and Python.

## Features

* Converts natural language questions into SQL queries
* Executes generated SQL queries on a MySQL database
* Displays generated SQL statements
* Shows query results in a formatted table
* Simple and responsive web interface

## Technologies Used

* Python
* Flask
* Gemini API
* MySQL
* HTML
* CSS

## Example Queries

* Show all employees
* Show employees with salary greater than 60000
* Show employees in HR department
* Display all IT employees
